# 完成标准

范围为目标游戏已有功能。输出真实修改和可运行画面；单独设计稿、截图或“以后可实现”不是完成改造。

## 视觉

- 主标题/关键控件保留厚实字形与墨色轮廓、贴纸切边/硬影和有机墨形，强度符合游戏情绪，正文清楚；不强制深紫、双色阵营、固定亮度或原作色卡。
- 玻璃属性面板与实体重点贴纸区分，场景/角色保留可见空间。
- 主行动体量/颜色/位置明确；不靠让所有项同时高亮来强调。
- 选中与focus可共存，危险/锁定/ready有非颜色提示。
- 图标轮廓一致，装饰不挡操作、正文、准星和数字。
- 保留目标真实名称、美术、数据，不默认复制原作Logo/地图/角色。

## 自适应设计

- 有项目证据支持的题材/体验、核心循环、信息优先级、设备与视觉保护区分析，推测已标明；没有照游戏分类名直接套预设。
- 角色色与实际数值、面板/文字/焦点/行动/危险含义明确，保留已有资源/阵营语义；自定义色可以完全位于原作五组之外。
- 检查实际背景、透明叠加和文字对比，主题主色与警示色冲突时仍可区分；颜色之外有标签/形状。
- 布局按玩家任务、密度和视角调整；不强制左菜单右角色，关键棋盘/准星/对白没有被遮挡。
- 预览/提交/取消/保存时机和操作成本适合目标玩法；没因主题新增无用确认或不存在的机制。
- 导航、即时告警、奖励分别决定动效，克制题材仍有反馈，快速玩法不等待装饰；减少动态优先。
- 游戏依据→颜色/布局/交互/动效的简短理由能对上真实实现；没有把“代码能加载”当成“审美判断正确”。

## 行为（有对应功能才测）

1. 鼠标、键盘与已有手柄进入同一focus；静止鼠标不抢焦点。
2. 按下后移出/取消/窗口失焦不粘住；一次确认只调用一次动作。
3. focus预览不保存，确认成功后勾与真实装备同步；返回恢复焦点。
4. 滑杆/方向/触控改真实数值；边界和禁用有原因。
5. 文本输入不触发WASD；模态/菜单不把开火/确认穿透游戏。
6. 暂停/继续/回主菜单/重开保留玩法与存档；在线继续运行有提示。
7. 快速返回/双击/换页没有旧回调复活；提交至多一次。
8. 结算首次确认只跳过，释放后第二次确认才执行；减少动态显示完整最终值。
9. 声音服从音量/静音，滑杆与hover不每帧刷音；未接音效说明。
10. 旋转/卸载释放输入；重复进入不累计监听。

## 尺寸、性能和交付

至少查看目标常用尺寸及更小尺寸。Web起点1280×720、1920×1080、844×390，竖屏项目390×844；测长中文、昵称、多卡片、字号缩放、安全区，所有内容可达且focus不在屏外。

减少动态后焦点、选中、错误、数字仍完整。关闭模糊/粒子风格仍由形状和排版成立；不为每个资源值每帧重建整页。运行与修改相关的构建/语法/现有检查并实际操作主流程；无需为纯视觉数值做机械测试，状态/提交/清理才值得逻辑测试。

最终说明改动屏幕、文件/预览、实际通过检查与未运行项，附代表画面。无运行条件就明确说，不能用原作截图冒充目标结果。
