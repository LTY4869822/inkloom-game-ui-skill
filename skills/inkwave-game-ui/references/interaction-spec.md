# 交互契约与状态迁移

原作机制的可迁移契约。先按adaptive-design.md确定项目交互与动效；tokens.source和下表数字是原作参考，时长/过冲/位移按题材、任务和设备调节。动作名、提交时点和快捷键服从目标项目。

## 状态分离

```text
rest → focus → pressed → focus
           ↘ blur → rest
focus/pressed → disabled（阻止提交，说明原因）
selected/equipped/ready 与以上状态正交
```

focus只表示当前操作目标。selected表示当前选择，equipped表示已保存装备，ready表示可以开始。失焦不能抹掉selected。禁用态保留轮廓和可读原因。

| 控件 | focus / preview | accept / change | edge / error |
|---|---|---|---|
| 主按钮 | 回正/局部墨水填充与可见焦点；原作位移.7u、scale1.045供参考 | 局部按压后恢复，强度按任务选择；单次动作 | 解释不可用原因 |
| 图片票券/装备卡 | 微倾、抬起、外圈、更新详情 | 勾选、确认音、小飞溅、保存回调 | 锁定标记 |
| 分段/分页 | 当前项高亮 | 一个胶囊移动，挤压可克制；原作450ms供参考 | 按项目规则处理环绕/局部反馈 |
| 滑杆 | 放大把手，显示确切值 | pointer capture，连续写真实值，音效节流 | clamp，边界轻撞 |
| 开关 | 焦点环 | 圆把手位移，文字/颜色同步 | 明确状态 |
| 文本输入 | 编辑期间输入归字段所有 | Enter提交，Esc按项目规则取消 | 字段旁解释非法值 |

按下、取消、失焦、指针离开、窗口blur、卸载都释放pressed/drag。打开菜单的Space不能同时让角色跳跃，关闭菜单的鼠标键不能变成开火。

## 导航和焦点所有权

- 语义通道为focus(id)、move(direction)、accept、back、tab(±1)、adjust(±step)。设备输入汇入它，声音和视觉监听同一状态。
- 按屏记忆最后焦点的稳定ID；返回恢复。目标不可用时选有效邻居。焦点自动滚进可视区域。
- 规则网格用行列导航；复杂布局设置邻接图，避免自动空间搜索跳到远处的START。
- 鼠标实际移动才接管focus，避免静止指针抢键盘焦点。换设备同步按键图例；触控不依赖hover。
- Web保留Tab/Shift+Tab标准导航。原作Tab用于分页是自定义游戏方案，不宜无差别照搬；肩键/QE按项目冲突表换页。
- 模态独占输入，关闭后恢复触发控件焦点。编辑字段不把W/A/S/D发送给菜单或游戏。
- accept/back/tab对held/repeat不连续触发；方向可以延迟重复，确认是一击一次。

## 预览与提交

```text
equippedId = 从游戏数据读取
focusId变化 → 详情=focusId，比较基准=equippedId
accept(focusId) → 调用现有equip → 成功后才更新equippedId与勾选
失败 → 保留旧equippedId，显示原因
```

属性条同时显示当前预览和灰色基准，增减带正负数。已有3D模型、2D立绘、武器图皆可，不额外造角色系统。外观原作即时保存，但目标有“预览→应用”时保留目标语义。

## 转场与生命周期

普通子菜单立即交换内容，再按项目选择短淡入/错峰/轻扫（原作轻扫520ms供参考）。返回视觉方向相反。完整泼墨可用于进出对局或章节等重要边界，并按游戏情绪选择是否需要；在遮满的中点交换一次场景。

每次转场生成token，迟到回调仅在token有效时执行。业务动作至多一次，不依赖animationend才能完成；隐藏标签、动画中断和减少动态模式都能到达最终状态。

spring(.34,1.56,.64,1)、spring2(.26,1.9,.5,1)、out(.22,1,.36,1)、in(.6,0,.8,.25)。游标spring k260/c20是原实现参考，不能直接填入所有引擎的“弹性”字段。积分dt上限.1秒并分步。

固定倾斜放外层、press放内层、视差放图片层，或使用独立translate/rotate/scale；入场不能覆盖焦点与倾斜。显示与命中区域一致。

## HUD

| 数据 | 表达 |
|---|---|
| 资源 | 形状稳定，液面/填充随真实值变化 |
| 不足 | 缺量/数值说明和局部否定，不只红闪 |
| 能力可用 | 一次ready爆发，持续可用提示与操作键 |
| 消耗/冷却 | 游戏事件驱动，不按装饰时长自算玩法 |
| 命中/受击 | 准星或资源附近局部反馈，遵守震屏设置 |
| 队友死亡 | 图标变体与复活时间 |
| 时间急迫 | 按玩法阈值逐级提升；原作60/10秒只适合相应计时玩法 |

世界坐标标记、地图展开、角色预览仍归引擎。不要假造HP、队友、计时和网络状态。装饰HUD透过指针，仅真正的地图目标等接收输入。

## 暂停和结算

暂停调用现有API，网络仅开菜单时明确对局仍运行。关闭后不沿用残留held input。

结算状态intro→counting→settled，动画不影响奖励入账：

```text
accept():
  if state != settled:
    renderFinalNumbersAndAwards()
    state = settled
    consumeInputUntilRelease()
  else:
    activateFocusedActionOnce()
```

首次确认跳过，释放后第二次独立确认才开下一局。点击空白跳过和点击实际按钮可按项目语义区分。XP跨等级分段填满再继续；减少动态直接展示最终值与奖章。

## 声音、减少动态、触屏

音效hook为hover/click/confirm/back/toggle/slider/error，接入现有音量设置，首次用户手势后启用。滑杆音最多约50ms一次，hover不每帧播放。静音视觉仍完整；未接声音要说明。

减少动态去掉视差、循环漂浮、滴墨拉伸、旋转、连闪、强飞溅、大位移；保留短淡入、勾选、数字和焦点轮廓。项目开关与系统偏好可合并。

手机按短边及可触尺寸布局，显示与命中共用坐标。一般以至少44×44 CSS px为迁移起点，按平台和实机验证。考虑安全区与拇指遮挡。竖屏提示不能锁死；未实现竖屏战斗时清楚说明并可返回。旋转/失焦释放全部触点。
